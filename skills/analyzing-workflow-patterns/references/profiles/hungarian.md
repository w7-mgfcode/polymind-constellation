# Hungarian explanation profile

## Prerequisites

- The user requests Hungarian output or the selected team language is Hungarian.

## Selection

Apply this profile to explanation and examples. Keep standard technical terms,
commands, paths, and code in their canonical language.

## Behavior

Explain the goal, actors, lifecycle, gates, artifacts, and failure handling in
Hungarian. Give one small and one scaled example. Keep keyword chains and
machine-consumed schemas unchanged unless the user asks otherwise.

## Validation

- Confirm the explanation is Hungarian while code, commands, and identifiers are
  unaltered.
- Confirm no content was lost through translation.
